跑戳日志 · postmarkTrip

把纸质邮戳卡数字化、结构化，长期积累成可检索的个人邮史档案。

识别只做「预填 + 人工确认」——不替你做判断，只把你从手打 20 个字段里解放出来。

▶ 进入识别演示 GitHub 仓库

演示是预录回放：不上传图片、不调用识别、不联网。真实系统要自己部署。

它解决什么

记录

卡片、邮戳、邮票、邮局、地点、来源（实地跑戳 / 求戳信），可筛选、可搜索、可统计。

识别

扫描后自动预填字段，人工点几次确认即可入库——不做全自动，因为盖印不是印刷。

重建

用电子模板把邮票与邮戳重新合成到虚拟卡片上：换模板、去污渍、换电子邮票。

分享

个人画廊 + 公共戳库（只读、可贡献），不做社交。

自己跑一份

需要 Docker（Windows / macOS 用 Docker Desktop，Linux 用 Docker Engine + compose 插件）。

git clone https://github.com/zhihancn/postmarkTrip.git
cd postmarkTrip
make up          # Windows: .\pmtrip.ps1 up

首次启动会自动生成 .env 并打印一次管理员口令。浏览器打开 http://localhost:9999，登录后请立刻改口令。

数据边界

原始扫描件、卡片记录、日期地点、.env、数据库、备份——永远不会离开你的机器。

会离开的只有你主动开启的：云端 VLM（送检的那张图）、本机 colnetApi（票图）、局域网扫描 Agent。没有遥测、没有心跳、没有「检查更新」。
